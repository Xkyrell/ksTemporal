# ksTemporal

A lightweight library for time manipulation, serialization and deserialization with built-in serializers.<br>
No external dependencies and less than 100 KB in size. For more information, see the [wiki](https://github.com/Xkyrell/ksTemporal/wiki).

The currently supported formats are:

- **Compact** - formats time in a concise numeric form such as `01:20:35`.
- **Textual** - formats time using human-readable units such as `1 hour 20 minutes 35 seconds`.

Requires JDK 8 or newer.

#### Reliability
Most of the library is immutable for predictable behavior. The library is tested with JUnit 5 for reliability.
